Evidence in an audit checklist must always be verified against the actual source
code, not written from memory or assumption. Even a thorough audit can contain
incorrect evidence references. The following cross-check steps should be
performed before finalizing any audit:

  1. For every file path cited in evidence, run `ls` or `test -f` to confirm
     the file exists.
  2. For every line number cited, use `grep -n` or `sed -n` to verify the
     content at that line matches what the evidence claims.
  3. For implementation-location claims (e.g., "feature X is in file Y"),
     verify with `grep` that the relevant code is actually in that file,
     especially when the codebase may have been refactored.

These checks take seconds and prevent incorrect evidence from being committed
to the repository.
