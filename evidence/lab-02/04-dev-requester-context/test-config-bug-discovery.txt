LESSONS LEARNED
===============

  1. Vitest include patterns with explicit extensions can silently exclude
     files if the extension doesn't match. No error or warning is emitted.

  2. Manual test count verification (comparing expected vs actual) is an
     effective way to catch this class of bug.

  3. Projects should consider adding a CI step that validates the number
     of test files on disk matches the number discovered by the test runner.

  4. When creating new test files, verify the extension matches the
     project's vitest include pattern before writing tests.
