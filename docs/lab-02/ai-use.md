## Reflection

พอมาลองใช้ AI agent ในการทำ lab ดูก็พบว่า AI agent มีประโยชน์มากในการทำงานที่มีรูปแบบซ้ำ ๆ (เขียน test, สร้าง component ตาม pattern เดิม, debug ปัญหาที่ต้องลองผิดลองถูกหลายรอบ) แต่ก็ต้องตรวจสอบอย่างเข้มงวด เนื่องจาก agent ชอบบอกว่า success เเล้วทั้งๆที่บางทีไม่ได้ตรวจสอบให้ครบถ้วนจริง เช่น อ้างตัวเลข test ที่ผ่านโดยไม่มี raw output รองรับ หรือ copy สถานะจากเอกสารเก่าโดยไม่เปิดไฟล์เช็คความจริงปัจจุบัน

ซึ่งสิ่งที่สำคัญที่สุดคือ ห้ามเชื่อคำสรุปของ AI โดยไม่มีหลักฐานประกอบ โดยทุกครั้งที่จะขอ raw terminal output กับเช็คหน้าเว็บจริง หรือให้ agent grep ไฟล์เช็คก่อนอ้างอิง จะพบว่ามีความคลาดเคลื่อนซ่อนอยู่เสมอ ไม่ว่าจะเป็นตัวเลขนับผิด, mapping BR/AC ผิดคู่, หรือ layout bug ที่ unit test มองไม่เห็น การทำงานแบบ TDD ร่วมกับ self-audit ที่ต้องมีหลักฐานไฟล์+บรรทัดจริงประกอบทุกข้อ ช่วยให้มั่นใจได้มากขึ้นว่างานที่ส่งจริงตรงกับสิ่งที่เอกสารอ้างไว้
